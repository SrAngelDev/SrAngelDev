## 🚀 Proyectos destacados

### 📦 NexoPostal --- Trabajo Fin de Grado

> Plataforma integral de logística y paquetería construida con una
> arquitectura distribuida y orientada a microservicios.

[![Repositorio](https://img.shields.io/badge/GitHub-NexoPostal-181717?style=for-the-badge&logo=github)](https://github.com/SrAngelDev/NexoPostal)

-   **3 aplicaciones Angular** diferenciadas para clientes, intranet y
    repartidores.
-   Backend basado en **ASP.NET Core y microservicios**.
-   Persistencia con **PostgreSQL** y estrategia **Database per
    Service**.
-   Autenticación, autorización y sistema de **roles/permisos**.
-   Comunicación y actualizaciones en tiempo real mediante **SignalR**.
-   Integraciones con **Stripe**, SMTP, mapas y geolocalización.
-   Contenedorización mediante **Docker y Docker Compose**.
-   Reverse proxy con **Nginx**.
-   Pipeline **CI/CD con GitHub Actions y GHCR**.
-   Testing unitario, de integración y E2E con **xUnit, Testcontainers y
    Playwright**.
-   Aplicación de patrones y buenas prácticas como **SOLID, DTOs y
    Result Pattern**.

**Stack:** Angular · TypeScript · ASP.NET Core · C# · PostgreSQL ·
Docker · Nginx · GitHub Actions · SignalR · Stripe.
